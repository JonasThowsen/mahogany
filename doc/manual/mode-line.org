* The Mode-line

The mode-line is a bar along the top of each output, drawn by Mahogany
itself. By default it shows the output's groups, with the one shown
marked, the title of the focused window, and the clock. The tiling area and
layer-shell surfaces such as bars from other programs leave it room.

The =mode-line= command toggles it. It has no default keybinding; run
it from the colon prompt (=C-t ;=), or bind it:

#+BEGIN_SRC lisp
  (mh::define-key mh::*root-map* (mh::kbd "m") #'mh::mode-line)
#+END_SRC

** What it shows

The configuration property =mh::*mode-line-segments*= lists the
segments from left to right; each is the name of a module:

- =:groups= :: the groups of the bar's output, the one it shows marked
  with the accent, the empty ones dimmed. A click on a group goes to
  it; the wheel over the bar goes through that output's groups.
- =:title= :: the focused window's title, shortened to the room left.
- =:network= :: the SSID when on wifi (through =iwctl= or =iw=), the
  interface when wired, "offline" otherwise.
  A click opens the [[file:wifi.org][wifi menu]].
- =:volume= :: the default sink's volume, through =wpctl=; a click mutes,
  the wheel changes it. Hidden without =wpctl=.
- =:brightness= :: the backlight, from =/sys/class/backlight=; the wheel
  changes it through =brightnessctl=. Hidden without a backlight.
- =:battery= :: the charge, with the icon following the level and red
  under 15%. Read every 30 seconds, and at once when the pointer comes
  over it. Hidden without a battery.
- =:date=, =:clock= :: weekday, day and month; HH:MM.
- =:center= :: the segments up to =:fill= are centred on the bar.
- =:fill= :: the rest of the segments go to the right end.
- a function :: called with the output, returning a string to show,
  or =nil= for nothing.

The default is =(:groups :title :center :date :clock :fill :network
:volume :brightness :battery)=: the groups and the window title on
the left, the date and the clock in the middle, the system on the
right. =*mode-line-padding*= (12) is the room between segments. The icons are Nerd Font glyphs; they need a
Nerd Font installed (Symbols Nerd Font is enough), and
=(config-system:set-config mh::*mode-line-icons* nil)= turns them off.
=mh::*icons*= maps their names to glyphs, for other glyphs or plain
characters.

*** Modules of your own

A module is defined with =define-mode-line-module=: its text, evaluated
at every redraw with =output= bound, and optionally an icon, a color,
what a click, the wheel and the pointer coming over it (=:on-hover=)
do, and a =:refresh= function run every =:interval= seconds for
anything that should be read asynchronously (=mh::run-async= runs a
program and calls back with its output). The text runs on the
compositor's main thread at every redraw, so it must be quick: anything
that can make it wait belongs in =:refresh=.

#+BEGIN_SRC lisp
  (defvar *weather* nil)

  (mh::define-mode-line-module :weather
      (:icon "☀" :interval 600
       :refresh (lambda ()
                  (mh::run-async '("curl" "-s" "wttr.in/Oslo?format=%t")
                                 (lambda (output code)
                                   (declare (ignore code))
                                   (setf *weather* (and output (string-trim '(#\Newline) output)))
                                   (mh::mode-line-update))))
       :on-click (lambda () (uiop:launch-program "xdg-open https://wttr.in/Oslo")))
    *weather*)

  (config-system:set-config mh::*mode-line-segments*
                            '(:groups :title :fill :weather :volume :battery :clock))
#+END_SRC

The module takes no room while its text is =nil=. Redefining a module
replaces it, live.

** Appearance

- =mh::*mode-line-theme*= :: the font and colors, a =mh/theme:theme=.
  The background and font colors are what they say; the border color
  marks the current group.
- =mh::*mode-line-height*= :: the height in pixels (28 by default).
- =mh::*mode-line-padding*= :: the space at the ends and between
  segments (8).
- =mh::*mode-line-position*= :: =:top= (the default) or =:bottom=.

#+BEGIN_SRC lisp
  (config-system:set-config
   mh::*mode-line-theme*
   (mh/theme:make-theme :font "Iosevka 13"
                        :font-color (cl-colors2:rgb 0.92 0.86 0.7)
                        :background-color (cl-colors2:rgb 0.16 0.16 0.16)
                        :border-color (cl-colors2:rgb 0.84 0.37 0.22)))
#+END_SRC

The segments, theme and timing can be changed while Mahogany runs; the
next redraw shows them. The position and height take effect when the
mode-line is shown again (run =mode-line= twice, or
=(mh::mode-line-stop)= then =(mh::mode-line-start)=).

** Timing

The mode-line is redrawn when groups change, and every
=mh::*mode-line-timeout*= milliseconds (1000) for the clock and the
window titles.

** Turning it off at startup

#+BEGIN_SRC lisp
  (config-system:set-config mh::*mode-line-enabled* nil)
#+END_SRC
