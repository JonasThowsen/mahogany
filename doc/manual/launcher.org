* The Launcher and Menus

Mahogany's menus are drawn by Mahogany itself: a prompt, what you
type, and the items that match it. Matching is fuzzy: the characters
you type must appear in order in an item, so =nvi= finds =Neovim= and
=gnb= finds =gnewbg=. While a menu is open it has the keyboard:

| Key                      | Does                                   |
|--------------------------+----------------------------------------|
| typing                   | narrows the list                       |
| =Down= / =Tab= / =C-n= / =C-j= | next item                        |
| =Up= / =C-p= / =C-k=     | previous item                          |
| =PageDown= / =PageUp=    | a page of items                        |
| =Return=                 | choose the selected item               |
| =C-Return=               | choose it anew (see below)             |
| =BackSpace=, =C-w=, =C-u= | delete a character, a word, everything |
| =Escape=                 | cancel                                 |

The pointer works too: hovering selects, a click chooses, the wheel
moves the selection.

** The launcher

The launcher is a set of menus, called modes. The commands:

- =launcher-all= (=s-SPC=) :: everything in one list, as Raycast has it:
  the windows open, the applications installed, the other groups of
  this screen, the other screens, every Mahogany command with its key,
  and the launcher's modes; each item says what it is, and typing
  narrows all of them at once. Applications and commands chosen before
  come first within their kind. A window comes before its application,
  so =Return= on =helium= goes to the Helium window that is open:
  =C-Return= starts another one instead, through the window's
  application (its =.desktop= file, found by the window's app id).
- =launcher-apps= :: start an application, from the =.desktop= files of
  the installed programs (=XDG_DATA_DIRS= and =~/.local/share/applications=).
  Applications that were started before come first. =C-Return= starts
  it through the =.desktop= file's "New Window" action when it has one
  (browsers and editors do), so a running application opens another
  window instead of showing the one it has.
- =launcher-commands= :: run any Mahogany command, with its keybinding shown.
- =launcher-windows= :: go to a window, in any group; =C-Return= starts
  another window of its application.
- =launcher-groups= :: go to a group.
- =move-window-to-group-menu= :: move the focused window to a group.
- =launcher-run= :: run a shell command, with the commands run before to choose from.
- =launcher-eval= (=C-t :=) :: evaluate a Lisp form in the running
  compositor and show its values in a message; the forms evaluated
  before are listed. The form runs on the main thread, as a command
  does, so it may touch any state. See [[file:live-changes.org][Changing Things While It Runs]].
- =launcher-load= :: load a Lisp file into the running compositor, as
  init.lisp is loaded; the Lisp files beside init.lisp are listed, and
  a path can be typed.
- =launcher-menu= :: a menu of all the modes.

In Lisp, =(mh::launcher :apps)= opens a mode by name.

*** Adding a mode

A mode is a few lines in =init.lisp=: what it lists, and what to do
with the choice. The items are rebuilt every time the menu opens.

#+BEGIN_SRC lisp
  (mh::define-launcher-mode :projects (:prompt "Project" :description "Open a project")
    :items (mapcar (lambda (dir)
                     (mh::make-menu-item (car (last (pathname-directory dir)))
                                         :data dir
                                         :detail "coding"))
                   (directory "~/coding/*/"))
    :action (lambda (dir)
              (uiop:launch-program (list "foot" "-D" (namestring dir)))))

  (mh::define-launcher-mode :web (:prompt "Search" :description "Search the web")
    :items '()
    :text-action (lambda (query)
                   (uiop:launch-program
                    (list "xdg-open" (format nil "https://duckduckgo.com/?q=~A" query)))))
#+END_SRC

=make-menu-item= takes the label shown, =:data= handed to the action,
=:detail= shown dimmer at the right, and =:keywords= matched as well as
the label. A mode with a =:text-action= accepts what was typed when no
item matches; one with an =:alternate-action= does that instead of
the =:action= for a choice made with =C-Return=. Modes appear in
=launcher-menu= in the order they were defined; redefining a mode
replaces it.

*** Matching

=mh::*menu-match-function*= is the function that scores an item
against what was typed; replace it to match differently, for instance
by prefix only:

#+BEGIN_SRC lisp
  (config-system:set-config
   mh::*menu-match-function*
   (lambda (filter text)
     (when (alexandria:starts-with-subseq filter text :test #'char-equal)
       (- (length text)))))
#+END_SRC

** Appearance

=mh::*menu-theme*= (font and colors; the border color marks the
selection), =mh::*menu-width*= (a fraction of the output's width, 0.4),
=mh::*menu-rows*= (12), =mh::*menu-padding*= (14) and
=mh::*menu-radius*= (12, the corners). =mh::*overlay-style*= =:plain=
makes menus, and everything else drawn over the desktop, square with a
thin border and the selection as a bar across the box; see
[[file:theming.org][Themes]].

** Interactive commands

Commands that ask for something — =colon=, =gmove=, =grename= — read
through the same menu. To read through rofi or a terminal instead:

#+BEGIN_SRC lisp
  (setf cl-interactive:*default-input-method* (make-instance 'mh::rofi-input-method))
#+END_SRC
