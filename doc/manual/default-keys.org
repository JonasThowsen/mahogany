* The Default Keys

Mahogany comes with two sets of keys: SUPER chords laid out as niri
has them (=h j k l= and the arrows are directions, Control moves the
window, Shift goes to the next screen), and the =C-t= prefix map of
StumpWM (=*root-map*=; =C-t ?= lists it). =s-S-SPC= (or
=describe-bindings=) shows everything bound right now: typing narrows
the list to the keys and commands that contain the text, Backspace
takes it back, and Escape (or a click) closes it. Both live in =lisp/default-bindings.lisp= and
=lisp/key-bindings.lisp=; init.lisp changes them with =define-key= and
=undefine-key= on =*top-map*=, see
[[file:kmap-keybindings.org][Customizing Keybindings]].

** Programs and menus

| Key          | Command               | What it does                           |
|--------------+-----------------------+----------------------------------------|
| =s-RET=      | =open-terminal=       | a terminal (=*default-terminals*=)     |
| =s-SPC=      | =launcher-apps=       | start an application                   |
| =s-S-SPC=    | =describe-bindings=   | the keys bound now                     |
| =s-M-SPC=    | =launcher-menu=       | the launcher's modes (wifi, themes, …) |
| =s-x=        | =launcher-commands=   | run a command by name                  |
| =s-;=        | =colon=               | the command prompt                     |
| =s-o=        | =launcher-windows=    | find a window                          |
| =s-M-l=      | =lock-session=        | lock                                   |
| =s-S-e=      | =shutdown-confirm=    | quit Mahogany                          |

** Groups (workspaces)

Each output has groups of its own, numbered 1, 2, 3 … and made as
they are asked for; these keys act on the output that has the focus.
See [[file:groups.org][Groups]].

| Key                        | Command                                  | What it does                      |
|----------------------------+------------------------------------------+-----------------------------------|
| =s-1= … =s-9=              | =select-group-N=                         | group N of this output, made when missing |
| =s-C-1= … =s-C-9=          | =move-window-to-group-N=                 | the window to group N             |
| =s-S-1= … =s-S-9=          | the same                                 |                                   |
| =s-d= / =s-u=              | =gnext= / =gprev=                        | the next or previous group        |
| =s-Page_Down= / =s-Page_Up= | the same                                |                                   |
| =s-C-d= / =s-C-u=          | =gnext-with-window= / =gprev-with-window= | the window along                 |
| =s-g= / =s-S-g=            | =launcher-groups= / =move-window-to-group-menu= | groups by name             |

** The C-t prefix

The StumpWM keys, for when SUPER is taken (Mahogany nested in another
compositor, say): =C-t= and then one of these. =C-t ?= lists them all,
with the same search as =s-S-SPC=.

| Key                       | Command                                   | What it does                      |
|---------------------------+-------------------------------------------+-----------------------------------|
| =C-t c=                   | =open-terminal=                           | a terminal                        |
| =C-t SPC=                 | =launcher-apps=                           | start an application              |
| =C-t "=                   | =launcher-windows=                        | find a window                     |
| =C-t x= / =C-t ;= / =C-t != | =launcher-commands= / =colon= / =run-shell-command= | a command, the prompt, a shell command |
| =C-t m=                   | =launcher-menu=                           | the launcher's modes              |
| =C-t 1= … =C-t 9=         | =select-group-N=                          | group N of this output            |
| =C-t g 1= … =C-t g 9=     | =move-window-to-group-N=                  | the window to group N             |
| =C-t g F1= … =C-t g F10=  | =select-group-N=                          | the same as =C-t N=               |
| =C-t g n= / =C-t g p=     | =gnext= / =gprev=                         | the next or previous group        |
| =C-t g N= / =C-t g P=     | =gnext-with-window= / =gprev-with-window= | the window along                  |
| =C-t g c= / =C-t g k=     | =gnew= / =gkill=                          | a new group; remove this one      |
| =C-t g l= / =C-t g m= / =C-t g M= | =grouplist= / =gmove= / =gmove-and-follow= | groups by name              |
| =C-t Left= … =C-t Right=  | =focus-left= … =focus-right=              | focus the frame in that direction |
| =C-t M-Left= … =C-t M-Right= | =move-window-left= …                   | move the window that way          |
| =C-t S-Left= … =C-t S-Right= | =focus-output-left= …                  | focus the screen that way         |
| =C-t o= / =C-t O=         | =next-frame= / =prev-frame=               | the next or previous frame        |
| =C-t n= / =C-t p=         | =next-view= / =previous-view=             | the windows hidden behind the frame |
| =C-t k=                   | =close-current-view=                      | close the window                  |
| =C-t s= / =C-t S= / =C-t R= | =split-frame-v= / =split-frame-h= / =remove-current-frame= | frames          |

** Keys and keyboard layouts

A key is matched twice: first as the layout types it (=Shift-2= is
=at= on a US keyboard, =quotedbl= on a Norwegian one), then as the
key itself with the modifiers held (=S-2=). So =s-S-2= works on every
layout, and =s-at= works too where =at= is on the 2. =s-;= is where
the US layout has it; on a layout without it, bind something else:

#+BEGIN_SRC lisp
  (define-key *top-map* (kbd "s-oslash") #'colon)   ; ø on a Norwegian keyboard
#+END_SRC

** Directions

The frame to the left, right, above or below is the nearest one that
way, on this screen or on the screen beside it, so the same keys walk
across monitors. Moving a window that way swaps it with what the
frame there shows; a window moved into an empty frame leaves its own
frame to a hidden window, if there is one. The functions behind the
commands take a direction: =(focus-in-direction :left)=,
=(move-window-in-direction :down)=, =(focus-output-in-direction :right)=,
=(move-window-to-output-in-direction :up)=.

** Autostart

=*autostart*= lists programs started with the session, each a list
of arguments or a shell command string:

#+BEGIN_SRC lisp
  (setf *autostart* '(("xwayland-satellite") ("nm-applet")))
#+END_SRC

A program that is not installed is logged and skipped.
