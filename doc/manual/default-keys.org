* The Default Keys

Mahogany comes with two sets of keys: SUPER chords, the way most
Wayland desktops have them, and the =C-t= prefix map of StumpWM
(=*root-map*=; =C-t ?= lists it). =s-k= (=describe-bindings=) shows
everything bound right now. Both live in =lisp/default-bindings.lisp=
and =lisp/key-bindings.lisp=; init.lisp changes them with
=define-key= and =undefine-key= on =*top-map*=, see
[[file:kmap-keybindings.org][Customizing Keybindings]].

** Keys and keyboard layouts

A key is matched twice: first as the layout types it (=Shift-2= is
=at= on a US keyboard, =quotedbl= on a Norwegian one), then as the
key itself with the modifiers held (=S-2=). So =s-S-2= works on every
layout, and =s-at= works too where =at= is on the 2. Keys such as
=s-[= and =s-;= are where the US layout has them; on a layout
without them, bind something else:

#+BEGIN_SRC lisp
  (define-key *top-map* (kbd "s-aring") #'gnext)   ; å on a Norwegian keyboard
#+END_SRC

** Autostart

=*autostart*= lists programs started with the session, each a list
of arguments or a shell command string:

#+BEGIN_SRC lisp
  (setf *autostart* '(("xwayland-satellite") "mako"))
#+END_SRC

A program that is not installed is logged and skipped.
