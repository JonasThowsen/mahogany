* Customizing Mahogany's Appearance

** Themes

A theme is one set of colors, a font and a wallpaper that everything
Mahogany draws takes from: the mode-line, menus and the launcher, the
on-screen display, toast messages, the frame borders and the
wallpaper. Switching themes changes all of them at once, live.

Mahogany comes with =tokyo-night= (the default), =catppuccin=,
=catppuccin-latte= (light), =nord=, =gruvbox=, =everforest=,
=kanagawa=, =rose-pine=, =matte-black=, =gavinok= (Gavin Freeborn's
StumpWM, raw: white on black in a small monospace font, a thin bar
with the group in brackets, square menus and messages with a thin
border, a white border on the focused window, his gaps) and =mahogany= (the colors it had before themes). The theme chosen last is remembered
across restarts.

Themes change on the fly, with no restart:

- =theme-picker= (=s-C-SPC=) shows the themes as a row of cards across
  the screen, as Omarchy's theme menu does, the one in use in the
  middle. Each card is a small desktop drawn in its theme: the
  wallpaper, the bar, a focused and an unfocused window with the
  theme's borders, gaps and text colors. =Left= / =Right= (or =Tab=,
  =C-n= / =C-p=) slide along; the band takes the colors of the card in
  the middle as it slides, and once it comes to rest that theme is put
  to use on the whole desktop, so holding a key runs through the
  themes without waiting for each. A letter goes to the next theme
  whose name starts with it; =Return= keeps the theme shown, =Escape=
  goes back to the one from before. A click on a card selects
  it, a second click keeps it; the wheel moves along.
  =*theme-picker-card-width*= (320) is the size of the middle card.
- =theme-menu= (the "Themes" mode of the launcher) does the same as a
  list, which can be narrowed by typing.
- =next-theme= and =previous-theme= cycle through them; =next-theme=
  is on =s-C-S-SPC=.
- =(set-theme :nord)= from the REPL or =launcher-eval= does the same.
  In init.lisp it pins the theme: every start then uses it, whatever
  was chosen in the menu. To start with a theme and still have the
  menu's choice remembered, set =*default-theme*= instead, which is
  used until a theme has been chosen:

#+BEGIN_SRC lisp
  (config-system:set-config mh::*default-theme* :gavinok)
#+END_SRC

=*theme-hooks*= are functions called with the theme each time one is
chosen (not while the menu previews), for theming other programs.

*** Defining a theme

=define-theme= names a theme and gives its colors as =#rrggbb=
strings (or =cl-colors2= rgb values). Only what differs from the
defaults needs giving:

#+BEGIN_SRC lisp
  (define-theme :mine
    :description "Blue on dark"
    :font "monospace 12"
    :foreground "#c0caf5"      ; text
    :background "#1a1b26"      ; panels: the mode-line, menus, messages
    :surface "#24283b"         ; second background; unfocused frame borders
    :accent "#7aa2f7"          ; the current group, the selection, focused frames
    :muted "#565f89"           ; details, empty frames
    :error "#f7768e"           ; error messages
    :wallpaper "~/Pictures/mine.png")
#+END_SRC

=:border-focus= and =:border-unfocus= override the border colors
(the accent and the surface by default), =:wallpaper-color= the
color shown without a wallpaper (the background by default).
Redefining the theme in use applies the change at once.

=:from= names a theme whose values are the defaults, so a theme can
be another with a change, or the same theme with something added:

#+BEGIN_SRC lisp
  (define-theme :nord-mine :from :nord :accent "#ebcb8b")
  (define-theme :gavinok :from :gavinok :wallpaper "~/backgrounds/gavinok.png")
#+END_SRC

=:settings= is a plist of configuration variables and the values they
have while the theme is in use; =set-theme= puts the previous values
back when another theme comes. That is how a theme shapes the bar and
the gaps, not only the colors:

#+BEGIN_SRC lisp
  (define-theme :sparse :from :matte-black
    :settings '(*mode-line-icons* nil *mode-line-marker* :brackets
                *overlay-style* :plain
                *mode-line-height* 20 tree:*window-gap* 0 tree:*output-gap* 0))
#+END_SRC

=*overlay-style*= is how everything Mahogany draws over the desktop
looks: =:card= (the default) rounds the corners of menus, messages,
the OSD, the key help, notifications and the tab bar, and marks the
selection on a chip inside the box; =:plain= draws them square with a
one-pixel border and the selection as a bar across the whole box, the
way StumpWM's windows look.

Files in =~/.config/mahogany/themes/= (=*theme-directories*=) that
contain =define-theme= forms are loaded at startup, and again by
=reload-themes=; a theme file is the place to keep each theme.

*** The wallpaper

The wallpaper is a PNG file, scaled to cover each output, keeping
its proportions. Each theme can have its own (=:wallpaper=); without
one, the output shows the theme's wallpaper color. =set-wallpaper=
(the =wallpaper= command asks for the file) shows another file with
any theme, until =(set-wallpaper nil)=:

#+BEGIN_SRC lisp
  (set-wallpaper "~/Pictures/today.png")
#+END_SRC

Each wallpaper is scaled to its output once and kept, so switching
back to a theme shows its wallpaper at once; =*wallpaper-renderings-kept*=
(4) is how many are kept, about 33 MB each at 4K.

*** Theming other programs

=*theme-hooks*= holds functions called with the theme after it has
been applied. That is where to theme programs outside the image, the
way Omarchy does: write a color file and let the program pick it up.
The colors are =cl-colors2= rgb values with components from 0 to 1:

#+BEGIN_SRC lisp
  (defun hex (color)
    (format nil "~2,'0x~2,'0x~2,'0x"
            (round (* 255 (cl-colors2:rgb-red color)))
            (round (* 255 (cl-colors2:rgb-green color)))
            (round (* 255 (cl-colors2:rgb-blue color)))))

  (defun theme-foot (theme)
    (with-open-file (out "~/.config/foot/theme.ini" :direction :output
                                                     :if-exists :supersede)
      (format out "[colors]~%foreground=~A~%background=~A~%"
              (hex (theme-foreground theme))
              (hex (theme-background theme)))))

  (push 'theme-foot *theme-hooks*)
#+END_SRC

*** Fonts

A theme's font (=:font= in =define-theme=, a Pango description) is
the mode-line's; menus, the launcher, messages and the on-screen
display use it two points larger. The default,
="JetBrainsMono Nerd Font,sans-serif 10"=, is a family list: a machine
without JetBrainsMono falls back to its sans-serif. The icons of the
mode-line need a Nerd Font either way, see [[file:mode-line.org][The Mode-Line]].

** Gaps and borders

An empty frame that is alone on its screen draws no border;
=(setf tree:*empty-frame-border* t)= draws it, as StumpWM does. Empty
frames beside others always show theirs.


Windows keep a gap from each other and from the edge of the screen,
and each has a border of its own, in the focused or unfocused border
color of the theme (the look of Omarchy and Hyprland). The widths are
layout pixels:

#+BEGIN_SRC lisp
  (set-gaps :window 10 :output 10 :border 2)   ; the defaults
  (set-gaps :window 0 :output 0 :border 1)     ; the look before gaps
#+END_SRC

=:window= is the whole gap between two windows, =:output= the gap to
the edge of the usable area (the mode-line excluded), =:border= the
border width. Without a window gap neighbouring frames share one
border, as StumpWM's do. =set-gaps= lays the windows out again at
once; the values are =tree:*window-gap*=, =tree:*output-gap*= and
=tree:*frame-border-width*=.

** Messages

A message (=toast-message=, and what commands say) is a rounded card
at the top right of the screen, as mako shows notifications, with the
theme's accent as its edge; an error message has the error color
there. =*message-gravity*= places it (=:gravity-top-right=,
=:gravity-center=, =:gravity-bottom=, …), =*message-margin*= is its
distance from the edge, =*message-width*= its width (long text
wraps), =*message-delay*= how long it stays in milliseconds.

** The wallpaper

A theme with no =:wallpaper= file shows a gradient of its wallpaper
color: a touch of the accent at the top left, darker at the bottom
right. =set-wallpaper= and =*wallpaper*= show a PNG file instead.

*** Themes of single components

=set-theme= fills =*mode-line-theme*=, =*menu-theme*=, =*osd-theme*=,
=*message-theme*= and =*message-error-theme*= (=mh/theme:make-theme=
values with a font, a font color, a background color and a border
color). Setting one of them afterwards changes that component alone,
until the next =set-theme=.

** Cursor Theming

Mahogany uses xcursor themes to customize the appearance of the
cursor. To set an xcursor theme, use the =mh::state-set-cursor-theme=
function:

#+BEGIN_SRC lisp
  (mh::state-set-cursor-theme
   mh::*compositor-state*
   "mahogany_default")
#+END_SRC

When =nil= is passed as the name argument, the theme is set to the
system's default theme.

This function can also be used to set the size of the cursor, which is
specified as an optional argument:

#+BEGIN_SRC lisp
  (mh::state-set-cursor-theme
   mh::*compositor-state*
   nil ; Use the default theme
   24 ; This is the default size.
   )
#+END_SRC

** Customizing the grab pointer

When a keybinding is in the process of being entered, the pointer
changes to signify that input is not being passed to clients. To
change the cursor used, you can set the =mh::grab-pointer-cursor=
configuration property:

#+BEGIN_SRC lisp
  (config-system:set-config mh::grab-pointer-cursor "mahogany_grab")
#+END_SRC

*** Adding custom grab pointer cursors

You can use arbitrary images for the grab pointer by
[[https://wiki.archlinux.org/title/Xcursorgen][adding a custom cursor theme]]. For the name of the cursor, use
something like =mahogany_grab= to differentiate it from the other
standardized cursor names. Activate that theme in mahogany, and
set =mh::grab-pointer-cursor= to the name that you chose.
